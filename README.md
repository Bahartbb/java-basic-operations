# Java Basic Operations

This project contains simple Java methods for basic mathematical operations.

## Features
- Addition
- Increment
- Decrement
- Negation

## Technologies
- Java
- Static methods
- Basic arithmetic operations

## Example Usage

```java
System.out.println(MathUtils.add(10, 5));      // 15
System.out.println(MathUtils.increment(10));   // 11
System.out.println(MathUtils.decrement(10));   // 9
System.out.println(MathUtils.negate(10));      // -10
```
